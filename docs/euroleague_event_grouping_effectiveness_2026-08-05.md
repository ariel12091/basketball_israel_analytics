# EuroLeague event-grouping effectiveness

Date: 2026-08-05  
Status: exploratory shadow-ETL evaluation; not connected to PostgreSQL or the
production application

## What was evaluated

The pure R state machine in `etl/euroleague/group_events.R` was evaluated in two
different ways:

1. exact comparison with manually labelled high-risk fixtures;
2. structural diagnostics across an initial 23 complete EuroLeague games from
   season 2025.

The later 100-game expansion is reported separately in
`docs/euroleague_possession_audit_100_games_2026-08-05.md`; it supersedes the
23-game run as the current broad result.

These results must not be combined into one accuracy percentage. The labelled
fixtures provide direct correctness measurements but are a development set.
The complete games provide broader coverage but do not have provider-supplied
ground-truth parent relationships.

remain useful QA signals.

## Rules added during the complete-game audit

The broad run found and fixed three relationships not represented in the first
fixture version:

- a technical FT trip followed by a personal FT trip with a different shooter;
- opposing same-clock technical fouls that offset while an ordinary personal
  FT trip remains active;
- a throw-in-foul FT followed by a later ordinary personal FT trip without an
  intervening live-ball event.

Each foul parent is now allowed to create only one shooter/team FT trip. The
new cases were manually labelled and added to the permanent fixture suite.

The audit also confirmed three period-ending offensive rebounds. These now
emit `period_end_offensive_rebound` endpoints rather than leaving an open
possession at `EP`/`EG`.

## Deterministic possession counter

`etl/euroleague/count_possessions.R` applies the grouping rules to every source
event and emits:

- one auditable row per possession;
- sequential game and team possession numbers;
- team/game possession totals;
- totals by endpoint rule;
- hard structural failures separately from softer review signals.

Repeated runs over the same 12,674 source rows produced identical results. All
23 sample games passed hard structural QA.

## Assessment

The implementation is effective enough for a shadow EuroLeague ETL and
full-season validation. It is not yet ready to publish canonical possessions to
the application.

Confidence by category:

- ordinary shots, rebounds, turnovers, and ordinary FT trips: 98-99%;
- explicit and-ones and four-point plays: 99% on the observed patterns;
- technical, throw-in, and interleaved special penalties: 90-95%;
- overall production readiness: approximately 95%, conditional on passing a
  full-season box-score and score-progression reconciliation.

The 100% labelled result is a regression guarantee for the 20 known patterns,
not an estimate that every future EuroLeague event will be classified correctly.

## Next release gate

Before database integration:

1. run the grouping function across every game in at least one full season;
2. reconcile points, FGA, FTA, offensive rebounds, defensive rebounds, and
   turnovers against box scores;
3. review every provisional incident and every game with possession difference
   above one;
4. expand fixtures for any newly observed event pattern;
5. only then map `synthetic_parent_order` to canonical integer
   `parent_action_id` values.
